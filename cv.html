Trabajo Fin de Máster

Metabarcoding para el análisis de diversidad fúngica y bacteriana en muestras ambientales

El TFM aborda el uso de metodologías de secuenciación y análisis bioinformático para estudiar comunidades bacterianas y fúngicas presentes en muestras ambientales.

Los principales temas estudiados incluyen:

  • Marcadores 16S rRNA.
  • Regiones ITS.
  • Secuenciación de nueva generación.
  • Control de calidad.
  • OTUs.
  • ASVs.
  • QIIME2.
  • DADA2.
  • Mothur.
  • Diversidad microbiana.
  • Procesamiento y análisis bioinformático.
Clinical Platform

Arquitectura de la plataforma

Proyecto personal orientado a construir una plataforma clínica moderna, modular y Linux-first para gestión de pacientes, seguimiento de tratamientos e incorporación de capacidades analíticas.

Arquitectura propuesta:

  • Frontend: React + TypeScript + Vite.
  • Backend: NestJS + TypeScript.
  • Base de datos: PostgreSQL.
  • Cache y procesamiento de tareas: Redis + BullMQ.
  • Worker analítico: Python.
  • Almacenamiento de objetos: S3 / MinIO.
  • Contenerización mediante Docker.
  • Arquitectura modular para separar dominios funcionales.

El objetivo es combinar ingeniería de software, datos clínicos y análisis predictivo en una plataforma que pueda evolucionar hacia herramientas de apoyo a la toma de decisiones.
